# UNNIR Consultoria

Site institucional de consultoria e desenvolvimento humano.

## Recursos

Apresentação de soluções, pilares, palestras, parceiros e canais de contato.

## Tecnologias

HTML, CSS e JavaScript; sem etapa de build npm na estrutura analisada.

## Executar localmente

Sirva os arquivos por HTTP; uma opção com Python 3 instalado:

```sh
git clone https://github.com/Felipegaldinos/UnnirConsultoria.git
cd UnnirConsultoria
python -m http.server 8000
```

Abra http://localhost:8000. Recursos de terceiros, quando usados, exigem conexão com a internet.

## Onde começar no código

- `index.html` — ponto de entrada para entender o projeto.

## Estado atual

Grande parte do conteúdo está em index.html. Revise textos e links ao atualizar informações institucionais.
